# ChatServer

A multithreaded TCP chat server and client application built with C++ and Winsock.

## Features

- TCP client-server communication
- Multiple simultaneous clients
- Multithreading
- User authentication with unique usernames
- Public messaging
- Private messaging
- Online user list
- Message timestamps
- Persistent chat history
- Message and username validation
- Server status monitoring
- Server-side shutdown command
- Graceful client disconnection
